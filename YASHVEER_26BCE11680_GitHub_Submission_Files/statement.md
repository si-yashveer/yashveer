# Project Statement

## Project Title

**Student Performance & Attendance Management System**

## Problem Statement

Managing student attendance, marks, grades, and performance information manually can be time-consuming and may lead to inconsistent records. A simple computerized system is needed to keep student academic information organized and make routine calculations easier.

This project develops a Python-based desktop application that combines student records, attendance, marks, grade calculation, and basic performance analytics in a single system.

## Scope of the Project

The project covers the following activities:

- Maintaining student information.
- Recording and managing attendance.
- Recording marks for academic evaluation.
- Calculating percentage and grade.
- Viewing student performance information.
- Presenting basic analytics through charts.
- Persisting information in an SQLite database.

The system is intended as an academic mini-project and can be extended later with authentication, advanced reports, export options, and additional analytics.

## Target Users

The primary target users are:

- **Students** - for viewing and understanding academic performance and attendance data.
- **Teachers / Faculty** - for maintaining student marks and attendance records.
- **Academic staff** - for organizing student information and reviewing performance summaries.

## High-Level Features

1. **Student Management**
   - Add and maintain student records.
   - Access stored student information.

2. **Attendance Management**
   - Record attendance data.
   - Review attendance information.

3. **Marks & Performance**
   - Store marks.
   - Calculate percentage.
   - Assign grades using the project's grading logic.

4. **Analytics**
   - Display basic performance summaries.
   - Generate visual charts using Matplotlib.

5. **Database**
   - Persist application data using SQLite.

6. **Graphical User Interface**
   - Provide a desktop interface using Tkinter for easier interaction.
