## Project Overview

The **Student Performance & Attendance Management System** is a Python-based desktop application designed to help manage student records, attendance, marks, grades, and basic performance analytics in one place.

The system uses a graphical user interface so that student information can be entered, updated, viewed, and analyzed without requiring direct database commands.

## Features

- Add and manage student records.
- Store attendance information.
- Record marks and calculate performance.
- Calculate percentage and grade.
- View student-wise performance information.
- Generate basic analytics and visualizations.
- Store data using SQLite.
- Simple desktop interface using Tkinter.

## Technologies / Tools Used

- **Python**
- **Tkinter** - graphical user interface
- **SQLite** - database management
- **Matplotlib** - charts and analytics

## Steps to Install & Run

1. Install Python 3.x.
2. Download or clone this project repository.
3. Open a terminal in the project folder.
4. Install the required Python packages.
5. Run the main Python application file.

Example:

```bash
python main.py
```

> Replace `main.py` with the actual entry-point filename of the submitted source code if it is different.

## How to Test


- Database initialization
